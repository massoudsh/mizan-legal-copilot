# صفحهٔ لندینگ میزان

> صفحهٔ معرفی استاتیک محصول برای نمایش ارزش پیشنهادی و مسیر درخواست دمو.

## مسئولیت‌ها
- معرفی میزان به‌عنوان کوپایلوت هوشمند ریسک حقوقی و رگولاتوری.
- نمایش قابلیت‌ها، فرایند سه‌مرحله‌ای تحلیل و پرسوناهای سازمانی.
- فراهم‌کردن مسیر مستقیم درخواست دمو از طریق ایمیل.
- حفظ تجربهٔ RTL، responsive و قابل استفاده با کاهش حرکت.

## قراردادها / Edge cases
- زبان سند فارسی و جهت آن RTL است؛ محتوای عددی و فنی در صورت نیاز باید جهت مناسب داشته باشد.
- ناوبری داخلی با anchor به بخش‌های `features`، `workflow`، `audience` و `contact` انجام می‌شود.
- صفحه بدون build یا JavaScript خارجی اجرا می‌شود.
- در نمایشگر کوچک، ناوبری متنی پنهان و کارت‌ها و مراحل به چیدمان تک‌ستونه تبدیل می‌شوند.

## منابع کد
- `landing/index.html:1` — ساختار semantic و محتوای صفحه
- `landing/styles.css:1` — توکن‌های طراحی، layout و responsive states
